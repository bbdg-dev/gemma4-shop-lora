# 실험 결과 요약

Gemma-4 다섯 크기(E2B · E4B · 12B · 26B-A4B · 31B)에 같은 데이터 · 같은 평가셋 · 같은 설정으로 LoRA 를 학습하고, 원본과 학습본을 비교했습니다 (9과제 × 5크기 = 45셀).
이어서 E2B 로 추가 실험 4가지(통합 어댑터 · LoRA 설정 · 데이터량 · 전량 학습)를 했습니다.

> 이 저장소에는 E2B · E4B 어댑터만 있습니다. 12B · 26B-A4B · 31B 는 결과만 참고용으로 싣습니다 (학습 후 성능이 E2B 와 같아 어댑터는 공개하지 않음).
> 평가 문항·모델 출력 예시는 학습 데이터 원문을 포함하므로 싣지 않았습니다.

---

## 1. 요약

- **9과제 모두 학습 효과가 있습니다.** 분류는 정확도 +0.4~+42%p, 추출은 F1 +0.16~+0.61, 생성 3과제는 다섯 크기 모두 학습본이 원본보다 유의하게 낫습니다 (승률 62~95%).
- **학습 후에는 모델 크기 차이가 거의 없습니다.** 자동 채점하는 분류·추출 6과제 중 5과제에서 다섯 크기 학습본의 성능이 같습니다 (핵심어추출은 1%p 이내). 예외는 상담사행동 하나로, 12B 가 E2B 보다 +2.6%p 높고 12B 를 넘으면 더 오르지 않습니다.
- **E2B + LoRA 로 충분합니다.** 학습한 E2B 는 분류·추출 6과제 모두에서 학습하지 않은 31B 보다 높습니다.
- **어댑터 1개로 8과제를 대신할 수 있습니다** (통합 어댑터 · 손해 없음 · 상담사행동은 오히려 +1.9%p).
- **데이터는 5천 건이면 효과의 86~93%, 2만 건이면 전량과 같습니다.**
- **남는 문제는 데이터·크기로 풀리지 않습니다.** 응답생성이 주문 조회 값을 지어내는 문제는 크기를 키워도, 데이터를 6.7배 늘려도 남습니다.

- 분류·추출의 학습 효과는 통화전체분류 12B (+0.4%p, 원본이 이미 96%) 를 빼고 모두 유의합니다. 생성 15셀은 모두 학습본이 유의하게 우세합니다.
- '학습 후 크기 차이' 는 학습본끼리 같은 문항으로 짝지은 비교(10쌍)입니다. 생성 과제 승률은 각 크기의 원본과 붙인 값이라 크기끼리 직접 비교하지 않습니다.

### 3-1. 분류 — 학습 후 다섯 크기가 같다 (상담사행동만 예외)

- **원본은 크기 순서를 따르지 않습니다.** 26B-A4B · 31B 원본은 "목록에 맞는 유형이 없다" 는 거절문을 내고, E4B 원본은 통화전체분류에서 목록에 없는 '주문' 을 91번 답했습니다.
- **학습 후에는 다섯 크기가 1~2%p 폭 안에 모입니다** (학습본끼리 10쌍 모두 본페로니 기준 유의하지 않음).
- **상담사행동만 크기 효과가 있습니다.** 12B 학습본이 E2B 학습본보다 +2.6%p (p=0.0009) 이고, 12B 를 넘으면 더 오르지 않습니다. 상한 약 66% 는 데이터가 만듭니다 — 같은 통화 이력에서도 다음 행동이 하나로 정해지지 않습니다 (바로 교환 접수할지, 상품 상태부터 확인할지).
- **남는 오류는 입력·라벨의 한계입니다.** 카테고리분류는 첫 문장만으로 교환/반품을 정할 수 없는 입력이 많고 (통화 전체를 보면 원본부터 92~96%), 의도분류는 '교환 ↔ 사이즈·색상교환' 라벨 경계가 상한을 만듭니다.

### 3-2. 추출 — 학습 효과가 가장 크다

- 원본은 무엇을 뽑아야 하는지 기준을 모릅니다 (핵심어: 작은 원본은 인사말까지 뽑고 큰 원본은 너무 적게 뽑음 · 슬롯: 직전 상담사 발화의 값까지 가져오거나 문장부호를 붙임).
- 학습 후 핵심어 F1 0.940~0.950, 슬롯 F1 0.938~0.948 로 같습니다. 슬롯의 공통 약점은 **상품명 ↔ 상품종류 경계** (상품명 F1 0.59~0.67) 로, 라벨 정의의 문제라 크기·학습으로 풀리지 않습니다.

### 3-3. 생성 — 학습본이 모두 우세, 승률 차이는 원본이 만든다

- 학습본은 정답과 비슷한 길이 (상담사 발화 25~30자 · 고객 발화 7~8자) 로 절차의 다음 단계를 말합니다. 원본은 해설·선택지를 나열하거나 역할을 바꿔 답해 실격되는 일이 많습니다 (응답생성 원본 실격 100건 중 E2B 22 · E4B 1 · 12B 55 · 26B-A4B 81 · 31B 14).
- **승률 순서는 원본의 실격 수를 따라갑니다.** 원본이 제대로 답하는 31B · E4B 에서 승률이 낮고, 원본이 스스로 실격하는 12B · 26B-A4B 에서 높습니다.
- **조회 값 지어내기**: 응답생성 학습본이 이력에 없는 상품명·주문일·주소를 말한 쌍이 크기마다 4~8쌍 있습니다. 정답 데이터가 상담사가 조회 화면을 보고 한 말이라, 학습본이 "화면 없이 화면 값을 말하는" 법을 배운 것입니다.
- **반복 루프**: 끝나지 않는 답이 크기마다 0~4건 (대부분 가림 문자 'ㅇㅇㅇㅇ' 반복).

## 4. 추가 실험 (E2B)

모두 같은 평가 문항으로 기존 E2B 학습본과 짝지어 비교했습니다.

### 4-1. 통합 어댑터 — 어댑터 1개로 8과제 (`adapters/E2B/multi`)

8과제의 학습 데이터를 섞어 (251,308행) 어댑터 1개를 학습했습니다. 행마다 그 과제의 프롬프트를 쓰고, LoRA 설정은 과제별 어댑터와 같습니다.

| 과제 | 과제별 어댑터 | 통합 어댑터 | 판정 |
|---|---|---|---|
| 카테고리분류 | 85.4% | 85.0% | 차이 없음 (p=0.60) |
| 고객의도분류 | 81.5% | 81.6% | 차이 없음 (p=0.93) |
| 통화전체분류 | 96.2% | 96.4% | 차이 없음 (p=0.75) |
| **상담사행동** | 64.2% | **66.1%** | **통합이 나음 (p=0.006)** |
| 핵심어추출 F1 | 0.940 | 0.943 | 같음 |
| 슬롯추출 F1 | 0.947 | 0.943 | 같음 |
| 고객응답생성 (원본 대비) | 95.0% | 98.0% | 학습본끼리 직접 판정 5승 4패 91무 — 차이 없음 |
| 응답생성 (원본 대비) | 77.5% | 78.0% | 학습본끼리 직접 판정 14승 17패 69무 — 차이 없음 |

- **손해 없이 대신합니다.** 상담사행동은 다른 과제의 통화 데이터를 함께 본 효과로 오히려 올랐습니다 (배송안내 F1 0.27 → 0.44 · 상품상태확인 0.42 → 0.55).
- 어댑터 크기는 과제별 1개와 같은 21.5MB 입니다 (8개 합계 172MB → 21.5MB).
- 대신 과제를 추가·수정할 때마다 전체를 다시 학습해야 합니다. 과제별 어댑터로 실험하고, 확정된 과제 묶음을 통합 어댑터로 내보내는 순서를 권장합니다.

### 4-2. LoRA 설정을 키우면 (MLP 포함 · r64 · 2에폭)

| 과제 | 기본 → 큰 LoRA | 판정 |
|---|---|---|
| 상담사행동 | 64.2% → **65.9%** (p=0.026) | 나아짐 — 12B 학습본(66.8%)과 차이 없음 (p=0.33) |
| 응답생성 | 원본 대비 77.5% → 76.0% · 학습본끼리 직접 판정 51% (p=0.86) | 차이 없음 · 반복 루프 2 → 4 |

- 큰 LoRA 어댑터(421MB)는 이 저장소에 넣지 않았습니다. 상담사행동은 통합 어댑터(66.1%)가 같은 수준입니다.

### 4-3. 데이터량 — 몇 건이면 충분한가

| 학습 건수 | 고객의도분류 정확도 | 슬롯추출 F1 |
|---|---|---|
| 0 (원본) | 61.9% | 0.340 |
| 1,000 | 70.6% | 0.826 |
| 5,000 | 78.8% | 0.902 |
| 20,000 | 80.9% · 전량과 차이 없음 (p=0.37) | 0.927 |
| 전량 | 81.5% (25,927건) | 0.947 (78,246건) |

- **1천 건이면 출력 형식을 익히고, 5천 건이면 전량 효과의 86~93%, 2만 건이면 전량과 거의 같습니다.**
- 새 도메인·새 과제는 5천 건으로 먼저 학습해 보고, 부족하면 2만 건까지 늘리는 것이 비용 대비 효율적입니다.

### 4-4. 응답생성 전량 (13.3만 건) 대 2만 건 — 다섯 크기 직접 판정

| 모델 | 전량 승 / 2만 승 / 무 | 전량 승률 | p |
|---|---|---|---|
| E2B | 20 / 11 / 69 | 54.5% | 0.15 |
| E4B | 13 / 11 / 76 | 51.0% | 0.84 |
| 12B | 16 / 14 / 70 | 51.0% | 0.86 |
| 26B-A4B | 20 / 15 / 65 | 52.5% | 0.50 |
| 31B | 17 / 15 / 68 | 51.0% | 0.86 |
| 합계 | 86 / 66 / 348 | 52.0% | 0.12 |

- **다섯 크기 모두 차이가 없습니다.** 데이터를 6.7배 늘려도 판정상 이득이 없습니다.
- 조회 값을 지어내 진 쌍은 전량 22 · 2만 15, 반복 루프는 전량 9 · 2만 3 — 데이터를 늘려도 줄지 않았습니다.
